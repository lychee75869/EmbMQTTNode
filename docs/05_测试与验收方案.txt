================================================================================
阶段5：测试与验收方案
项目名称：EmbMQTTNode 嵌入式 MQTT 环境监测节点
================================================================================

一、测试环境
--------------------------
- 开发机：Windows + WSL2 Ubuntu / 虚拟机 Ubuntu
- 编译器：gcc (Ubuntu 11.x)
- 依赖库：libmosquitto-dev、libsqlite3-dev
- MQTT Broker：mosquitto（Docker 或本地安装）

二、单元测试
--------------------------

1. sensor 模块测试
   命令：
       cd tests && make test_sensor && ./test_sensor
   预期结果：
       - 输出 5 组模拟传感器数据
       - 显示 "sensor test passed"

2. storage 模块测试
   命令：
       cd tests && make test_storage && ./test_storage
   预期结果：
       - 3 条数据写入 SQLite
       - 读取 3 条数据，验证时序正确
       - 删除后剩余 0 条
       - 显示 "storage test passed"

三、集成测试
--------------------------

1. 启动 MQTT Broker
       docker run -it -p 1883:1883 eclipse-mosquitto
   或本地安装：
       sudo apt install mosquitto
       mosquitto -v

2. 编译主程序
       cd src && make

3. 运行程序（前台）
       cd src && ./embmqttnode -c ../config/node.conf

4. 订阅 MQTT 主题验证数据
       mosquitto_sub -h 127.0.0.1 -t "embmqttnode/data"

5. 预期结果
   - 终端每 5 秒打印一次采样数据
   - mosquitto_sub 收到 JSON 格式消息
   - 断开 MQTT Broker 后，程序将数据存入 data.db
   - 恢复 Broker 后，历史数据被补发

四、性能/稳定性测试
--------------------------
- 连续运行 30 分钟，观察是否崩溃或内存泄漏
- 使用 valgrind 检查：
       valgrind --leak-check=full ./embmqttnode -c ../config/node.conf

五、验收检查清单
--------------------------
- [ ] 单元测试 test_sensor 通过
- [ ] 单元测试 test_storage 通过
- [ ] 主程序编译无警告
- [ ] MQTT 在线时数据实时上报
- [ ] MQTT 离线时数据存入 SQLite

六、常见故障排查
--------------------------
问题1：编译提示找不到 mosquitto.h
解决：sudo apt install libmosquitto-dev

问题2：运行时报 sqlite 锁或 database locked
解决：检查是否同时运行了多个进程访问同一个 data.db

问题3：MQTT 连接失败
解决：检查 broker_host/broker_port，确认 mosquitto 已启动且防火墙未拦截 1883
