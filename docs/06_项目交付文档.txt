三、快速开始
--------------------------

1. 安装依赖（Ubuntu/WSL）
       sudo apt update
       sudo apt install build-essential libmosquitto-dev libsqlite3-dev

2. 编译主程序
       cd src && make

3. 启动 MQTT Broker（本地测试）
       sudo apt install mosquitto
       mosquitto -v

4. 运行程序
       cd src && ./embmqttnode -c ../config/node.conf

5. 订阅查看数据
       mosquitto_sub -h 127.0.0.1 -t "embmqttnode/data"

6. 运行单元测试
       cd tests && make && ./test_sensor && ./test_storage
