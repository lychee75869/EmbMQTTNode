================================================================================
阶段3：硬件选型清单
项目名称：EmbMQTTNode 嵌入式 MQTT 环境监测节点
================================================================================

一、核心开发板
--------------------------

方案A（推荐）：香橙派 Orange Pi Zero 2 / Zero 3
- 主控：全志 H616 / H618，四核 Cortex-A53
- 内存：512MB / 1GB
- 接口：GPIO 26pin、I²C、SPI、UART、USB、百兆网口、WiFi
- 价格：约 100-180 元
- 优势：价格便宜、ARM64 生态、社区资料丰富、有 GPIO 排针
- 适用：本项目所有功能

方案B（稳妥）：树莓派 Raspberry Pi Zero 2 W / 4B 2GB
- 主控：Broadcom BCM2710A1 / BCM2711
- 内存：512MB / 2GB
- 接口：GPIO 40pin、I²C、SPI、UART、USB、WiFi、蓝牙
- 价格：约 200-400 元
- 优势：文档最全面、生态最好、稳定性高
- 适用：本项目所有功能

方案C（极简）：全志 V3s（荔枝派 Nano / LicheePi Zero）
- 主控：全志 V3s，ARM Cortex-A7
- 内存：64MB DDR2（片上）
- 接口：I²C、SPI、UART、以太网
- 价格：约 50 元
- 优势：成本低、适合跑定制 Linux
- 缺点：需要自己编译镜像，新手不友好

推荐：第一次做选 香橙派 Zero 2 或 树莓派 Zero 2W。

二、传感器模块
--------------------------

传感器A（推荐）：BMP280 温湿度气压模块
- 接口：I²C / SPI
- 量程：温度 -40~85℃，气压 300~1100 hPa
- 价格：约 10-20 元
- 优势：精度高、资料多
- 接线：VCC->3.3V，GND->GND，SCL->I2C_SCL，SDA->I2C_SDA

传感器B：SHT30 温湿度模块
- 接口：I²C
- 量程：温度 -40~125℃，湿度 0~100%RH
- 价格：约 15-30 元
- 优势：湿度测量更专业
- 注意：本项目 BMP280 已足够，可后续扩展 SHT30

四、软件依赖环境
--------------------------
- 开发板系统：Armbian / Debian / Raspberry Pi OS
- 编译器：gcc 或交叉编译器 aarch64-linux-gnu-gcc
- 依赖库：libmosquitto-dev、libsqlite3-dev、libgpiod-dev
- 调试工具：minicom / picocom、gdb、strace

五、预算汇总（香橙派方案）
--------------------------
- 香橙派 Zero 2：120 元
- BMP280 传感器：15 元
- MicroSD 卡：20 元
- USB-TTL：10 元
- 杜邦线：5 元
- LED + 电阻：2 元
- 电源：15 元
- 合计：约 187 元

六、采购建议
--------------------------
1. 先购买开发板 + 传感器 + SD 卡即可开始软件开发。
2. 电源可用手机 5V 充电器临时替代。
3. 不用急于买 USB-TTL，如果板子带 HDMI 或 SSH 网络可用，串口调试可后续补充。
