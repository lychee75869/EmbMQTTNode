================================================================================
阶段1：项目立项与需求分析
项目名称：EmbMQTTNode 嵌入式 MQTT 环境监测节点
================================================================================

一、项目背景
--------------------------
针对 Linux 嵌入式应用开发岗位的技能需求，设计并实现一个完整的物联网终端节点。
项目以 C 语言开发，运行在 ARM Linux 开发板上，采集环境温湿度/气压数据，通过 MQTT
协议上报到云端，同时具备本地缓存、断网续传、LED 状态指示等能力。

二、项目目标
--------------------------
1. 掌握 Linux 系统编程：文件 I/O、多线程、进程守护、信号处理、配置解析。
2. 掌握嵌入式硬件交互：I²C 设备驱动、GPIO 控制、传感器数据采集。
3. 掌握物联网通信：MQTT 协议、网络编程、断网重连、数据缓存。
4. 产出可直接写入简历的完整项目：需求文档、设计文档、源码、测试报告。

三、需求范围
--------------------------
【功能需求】
F1. 定时采集环境数据（温度、湿度、气压），采集周期可配置（默认 5 秒）。
F2. 通过 MQTT 将数据上报到云端 Broker，Topic 可配置。
F3. 支持断网本地缓存，网络恢复后补发历史数据。
F4. 通过 LED 指示灯展示设备运行状态：正常快闪、异常慢闪。
F5. 支持配置文件化，避免硬编码参数。
F6. 支持以守护进程方式后台运行，并记录系统日志。

【非功能需求】
NF1. 稳定性：7x24 小时运行，异常不崩溃，自动恢复。
NF2. 可移植性：传感器访问层抽象，便于切换真实 I²C 与模拟数据源。
NF3. 可维护性：代码模块化，Makefile 构建，单元测试覆盖核心逻辑。
NF4. 资源占用：内存占用 < 20MB，CPU 占用 < 5%（ARM Cortex-A53）。

四、目标用户
--------------------------
- 应届毕业生求职 Linux 嵌入式应用开发岗位
- 物联网平台开发者需要参考终端节点实现

五、技术约束
--------------------------
- 编程语言：C 语言（C99/C11）
- 操作系统：Linux（开发板为 ARM 架构）
- 构建工具：GNU Make + GCC
- 依赖库：libmosquitto（MQTT 客户端）、SQLite3（本地缓存）、libgpiod（GPIO）
- 硬件接口：I²C、GPIO

六、验收标准
--------------------------
- [ ] 编译通过，生成 embmqttnode 可执行文件
- [ ] 模拟传感器版本在 Linux/WSL 上可运行并打印数据
- [ ] MQTT 能成功连接本地 Broker 并发布消息
- [ ] 断网时数据写入 SQLite，恢复后补发
- [ ] 代码通过静态检查（gcc -Wall -Wextra 无警告）
- [ ] 提供完整的 README 和测试报告

七、风险与应对
--------------------------
风险1：硬件到货延迟。
应对：先实现模拟传感器版本，所有硬件相关代码通过抽象层隔离，后续替换驱动即可。

风险2：MQTT Broker 搭建复杂。
应对：使用 Docker 一键启动 mosquitto，或连接公共测试 Broker。

风险3：交叉编译环境配置困难。
应对：优先使用开发板原生编译（板载 GCC），或提供交叉编译 Makefile 模板。
